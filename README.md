# HR Analytics Project

## Project Objective
To analyse employee data and find why employees are leaving the company and how to improve retention.

## Tools Used
- Excel, Power BI, Tableau and MySQL

## Key Analysis Done
- Attrition Rate by Department
- Attrition by Age, Gender and Salary
- Average Tenure of Employees
- Performance vs Salary Analysis
- Work-life Balance Impact

## Key Insights
- Highest attrition is in Sales department
- Employees with low salary hike are leaving more
- New employees (0-2 years) have highest attrition

## Business Recommendation
- Focus on retention for new joiners
- Review salary hike policy
- Improve work-life balance for high attrition teams
